OSI Model

The OSI model explains how data travels through a computer network. It has seven layers.

The 7 Layers

1. Physical – Transmits bits through cables or wireless signals.
2. Data Link – Transfers frames within a local network. Example: MAC address.
3. Network – Routes packets between networks. Example: IP address.
4. Transport – Provides end-to-end data delivery. Examples: TCP and UDP.
5. Session – Establishes and manages communication sessions.
6. Presentation – Handles data format, encryption, and compression.
7. Application – Provides network services to applications. Examples: HTTP, DNS, SMTP.
